# 하루의 시작 — 아침 명상 & 마인드셋 저널 (Morning Meditation & Mindset Journal)

매일 아침 마음의 평온을 찾고, 새로운 활력과 다짐으로 하루를 시작할 수 있도록 돕는 웹 애플리케이션입니다.

---

## 🌿 주요 기능

1. **STEP 1. 아침 명상 사운드 (YouTube 임베드)**
   - 매일 엄선된 명상/이완 유튜브 음악 자동 추천 (432Hz 숲속 피아노, 티베트 싱잉볼, 528Hz 주파수 등)
   - 방해 없는 인앱 플레이어에서 바로 감상
   - 원하는 음악으로 교체하거나, 내가 좋아하는 유튜브 링크 직접 등록 기능
   - 4-7-8 원형 호흡 가이드 및 명상 타이머(5분, 10분, 15분, 20분) 탑재

2. **STEP 2. 오늘의 마인드셋 (영감의 글)**
   - 활기차고 새로운 마음가짐을 일깨우는 명언/철학 글귀 매일 제공 (마르쿠스 아우렐리우스, 법정 스님, 헬렌 켈러 등)
   - 생각을 확장해 주는 '오늘의 사색' 질문 제시
   - 언제든 다른 영감의 글을 읽을 수 있는 리프레시 버튼

3. **STEP 3. 나의 마음가짐 기록 (아침 저널링)**
   - 명상 후 지금 내 마음에 머무는 기분/감정 태그 선택 (평온함, 감사함, 활기참, 몰입 등)
   - 오늘 하루를 대하는 다짐과 소회를 작성하는 저널 에디터
   - 작성 즉시 안전하게 브라우저 로컬 스토리지에 자동 저장 (Auto-save)
   - '오늘의 명상 & 다짐 완료하기' 체크 시 연속 루틴(Streak) 달성 기록

4. **과거 기록 보관 및 키워드 검색**
   - 상단 `기록·검색` 버튼을 통해 과거 날짜별 캘린더 이동 지원
   - 작성한 일기 내용, 음악 제목, 글귀를 실시간으로 검색할 수 있는 키워드 검색창
   - 데이터 백업(JSON 다운로드) 및 복원(JSON 불러오기) 지원으로 데이터 영구 보존

## 🚀 실행 방법

### 방법 1. 간편 실행 (더블 클릭)
프로젝트 폴더 내 **`start.bat`** 파일을 더블 클릭하면 브라우저가 자동으로 열리며 앱이 실행됩니다.

### 방법 2. 터미널 실행
```bash
# 개발 서버 시작 (브라우저 자동 오픈)
npm run dev -- --open
# 또는
bun run dev -- --open
```

접속 주소: `http://localhost:3000` (또는 터미널에 표시되는 로컬 URL)
