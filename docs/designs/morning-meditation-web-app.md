# Design: Morning Meditation & Daily Mindset Web App

- **Generated by**: `/gstack-office-hours` on 2026-10-27
- **Status**: APPROVED (Ready for Implementation)
- **Mode**: Startup / Commercial MVP
- **Target**: Clean Single-Page Web Application (React + Vite + Tailwind + LocalStorage/IndexedDB)

---

## 1. Problem Statement
바쁜 일상을 시작하는 현대인은 감정 기복과 불안을 다스리고 활기찬 하루를 열기 위해 명상과 마인드셋 루틴을 원하지만, 여러 앱(유튜브, 타이머, 메모장, 일기 앱)을 번갈아 쓰며 발생하는 높은 진입 마찰(Friction)과 피로감으로 인해 꾸준한 루틴 유지에 실패합니다.

---

## 2. Demand Evidence & Status Quo
- **수요 증거 (Dogfooding)**: 창업자 본인이 직접 매일 아침 명상 음악을 찾고, 영감 글을 읽고, 다짐을 기록하는 과정에서 겪는 절실한 문제를 해결하기 위해 직접 사용하고자 함.
- **기존 해결 방식의 한계 (Status Quo)**:
  - 유튜브에서 적절한 명상 음악을 매일 검색해야 하는 번거로움과 알고리즘 피로.
  - 마인드셋 글을 따로 찾아 읽고, 느낀 점을 별도의 메모 앱에 파편화되어 기록.
  - 일련의 과정이 분절되어 있어 아침 시간 낭비 및 지속성 저하.

---

## 3. Core Feature Requirements
1. **아침 명상 음악 (YouTube) 큐레이션 및 인앱 재생**:
   - 매일 엄선된 아침 명상/이완 유튜브 음악 추천
   - 앱 내부에서 방해 요소(댓글, 추천 영상 등) 없이 몰입할 수 있는 깔끔한 임베드 플레이어
   - 타이머 기능(5분, 10분, 15분, 자유) 연동
2. **오늘의 활력 & 새 마음가짐 글 (Daily Mindset)**:
   - 매일 아침 새로운 영감과 활기를 불어넣는 엄선된 글/아포리즘 제공
   - 차분하고 정돈된 타이포그래피로 몰입감 극대화
3. **아침 마음가짐 저널링 (Morning Journaling)**:
   - 명상과 글을 접한 후 바로 나의 다짐과 소회를 작성할 수 있는 직관적인 작성 창
   - 자동 저장(Auto-save) 지원
4. **아카이빙 및 날짜별 검색 (History & Search)**:
   - 과거 날짜별로 제공된 음악, 글, 내가 작성한 마음가짐을 한눈에 볼 수 있는 캘린더 및 타임라인 뷰
   - 검색창을 통해 과거 작성한 글의 키워드 검색 지원
   - 데이터 백업 및 복원 (JSON 내보내기/가져오기)

---

## 4. Technical Architecture (Approach A)
- **Frontend Stack**: React 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons
- **Storage Layer**: IndexedDB / LocalStorage (브라우저 영구 보관, 서버 없이도 100% 로컬 프라이버시 보장)
- **Media Player**: YouTube IFrame API (광고나 추천 영상 등 산만함을 최소화한 미니멀 플레이어)
- **Design System**: 미니멀리즘 젠(Zen) 스타일, 다크/웜톤 뉴트럴 테마, 감성적인 여백 및 부드러운 애니메이션
